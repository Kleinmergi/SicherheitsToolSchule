# Infoportal-Konfiguration

Die Loginadresse folgt `https://schule-infoportal.de/login/{SCHULKENNUNG}`. Administratoren können die Schulkennung oder die vollständige URL eintragen. Es werden keine undokumentierten API-Endpunkte verwendet. Provider-Reihenfolge: offizielle API, offizieller Export, CSV, Excel, manuelle Pflege, DemoProvider.
