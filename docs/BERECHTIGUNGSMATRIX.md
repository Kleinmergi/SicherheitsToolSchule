# Berechtigungsmatrix

| Rolle | Kernrechte |
|---|---|
| Administrator | Schule, Benutzer, Rollen, Import, Übungen, Freigaben, Dokumente, Kalender, Maßnahmen, Audit, sensible Daten |
| Sicherheitsbeauftragter | Übungen, Anwesenheit, Dashboard, Dokumente, Umfragen, Kalender, Maßnahmen |
| Schulleitung | Freigaben, Dashboard, Berichte, Maßnahmen |
| Lehrkraft | mobile Anwesenheitsmeldung, Feedback |
| Sekretariat | Import, Drucklisten, Dashboard |
| Beobachter | Beobachtungen mobil erfassen |
